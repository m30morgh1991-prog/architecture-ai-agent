# Bug Hunt — PR #130 Autodesk snapshot binding fail-closed correction

## Scope
This stacked follow-up corrects a fail-open condition in the Python Autodesk evidence validator. It does not add new Autodesk extraction capabilities or change the AIE source-of-truth model.

## Bug Hunt
The validator previously trusted `snapshot_binding_status` from the same JSON envelope it was validating. An untrusted export could claim `VERIFIED` and, when INSUNITS was populated, be promoted to READY even though the active in-memory AutoCAD Database was not independently bound to the on-disk DWG bytes. This was a false pass risk.

## Reproduction
1. Create a valid evidence envelope with matching before/after/current source SHA-256 values.
2. Set source_profile.insunits to Millimeters.
3. Set source_integrity.snapshot_binding_status to VERIFIED.
4. Call inspect_autodesk_export().
5. Before the fix, the result could be READY although no independent in-memory snapshot proof existed.

## Root Cause
The validator treated an exporter-supplied status string as trusted evidence. Hash continuity proves the on-disk source bytes match the declared SHA-256; it does not prove the AutoCAD in-memory Database snapshot is byte-identical to those bytes. The exporter cannot attest its own missing proof.

## Regression
The adapter now ignores exporter-supplied snapshot verification claims and keeps accepted exports at NEEDS_REVIEW until an independently verifiable binding proof is designed and implemented. A new negative regression test covers a forged VERIFIED claim with valid declared units. Existing hash mismatch, source mutation, malformed envelope, and authority-boundary checks remain intact.

## Required fail-closed states
- Missing source/export, malformed JSON, schema mismatch, malformed entity identity, hash mismatch, or read-only invariant failure -> BLOCKED.
- Matching disk hashes without independent in-memory snapshot binding -> NEEDS_REVIEW.
- UNKNOWN, NEEDS_REVIEW, and BLOCKED never become PASS based on an untrusted payload field.
- No evidence state grants permission to edit a drawing or promotes architectural semantics.
