# Bug Hunt — H100 Scale/Unit Fail-Closed Contract (PR #102)

## Bug Hunt

## Scope
Refresh the deterministic scale/unit evidence contract and its standard-library regression tests onto current main after PR #101.

## Findings
Scale/unit evidence must not return PASS when the resolved unit is UNKNOWN, unsupported, malformed, or conflicting. Truthy flags alone are not authoritative unit evidence.

## Reproduction
Run `python -m unittest tests.test_scale_unit_evidence -v` and inspect the exact-head PR diff for the evaluator, negative tests, state checkpoint, and this evidence record.

## Root Cause
The prior contract accepted evidence flags without sufficiently validating the normalized unit and the consistency of evidence before allowing a PASS state.

## Regression
The change strengthens deterministic validation and adds negative tests for unknown units, unsupported labels, conflicting units, normalization, and direct construction of invalid PASS-like evidence. No Golden DWG asset is changed.

## Required fail-closed states
UNKNOWN, SOURCE_REQUIRED, NEEDS_REVIEW, ABSTAIN, and BLOCKED are not PASS. A declared unit alone does not prove drawing scale or dimension-to-geometry association. H100 remains active; H101 remains locked.

## CI Verification
Exact-head PR CI, Runtime Tests, Mandatory Bug Hunt, and applicable Golden regression must complete successfully before merge. The initial Mandatory Bug Hunt run failed only because the PR-specific evidence file was absent; this file addresses that reported blocker. The rerun must still pass before Green is claimed.

## Affected Contracts
`runtime/scale_unit_evidence.py`, `tests/test_scale_unit_evidence.py`, `PROJECT_STATE.md`, and this file. No Golden DWG files are modified.

## Risk Classification
Medium: unit errors can corrupt dimensional interpretation. Mitigation is conservative validation and fail-closed behavior for ambiguous or unsupported evidence.

## Negative Tests
- UNKNOWN unit cannot produce PASS.
- Unsupported unit labels cannot produce PASS.
- Conflicting unit signals cannot produce PASS.
- Whitespace/case normalization does not bypass validation.
- Direct construction cannot create an invalid PASS state.
- Native DWG unit declaration alone does not establish drawing scale.
