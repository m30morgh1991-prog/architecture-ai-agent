# Bug Hunt — PR #132 AutoCAD 2020 host compatibility

## Bug Hunt

PR #132 adds an AutoCAD 2020 target to the existing read-only Autodesk evidence extractor. The implementation is deliberately an evidence adapter; it does not own PlanModel, ConstraintMap, BIM semantics, architectural rules, or edit authorization.

The previous Mandatory Bug Hunt failure was a documentation-contract failure, not a C# or runtime test failure: the report used headings such as `## Findings` and `## Reproduction / validation`, while the gate requires exact section headings. The gate correctly blocked the PR instead of accepting incomplete evidence. This correction supplies the required exact headings and explicit regression / negative-test evidence. It does not claim that the AutoCAD host has been tested.

## Reproduction

1. Run the Mandatory Bug Hunt workflow for PR #132.
2. Inspect the job log for `MISSING_SECTION` and `MISSING_TOKEN` messages.
3. Run the gate again after this report update; it must accept the exact required headings and tokens outside fenced code blocks.
4. Run PR CI Gate and Runtime Tests on the new exact PR head.
5. Separately, on a compatible Windows host with AutoCAD 2020 installed, build the net47 target and NETLOAD the plugin against a disposable DWG copy. This host test is still NOT_RUN.

## Root Cause

The Bug Hunt evidence validator requires exact headings and explicit tokens. The prior report contained equivalent information under different heading names, so the validator correctly treated the required evidence as absent. A transient GitHub checkout connection failure also occurred during the job, but checkout succeeded on retry; it was not the cause of the final gate failure.

The AutoCAD compatibility change itself addresses a separate framework issue: the original plugin targeted only net8.0-windows, while AutoCAD 2020 requires .NET Framework 4.7. The shared source now conditionally uses the framework-provided JavaScriptSerializer for net47 and System.Text.Json for net8, and avoids Convert.ToHexString on the net47 path.

## Regression

- The focused compatibility contract tests verify both target frameworks, host-local Autodesk references, conditional serializers, framework-compatible hashing, and read-only safety boundaries.
- The Bug Hunt gate must reject missing exact headings, missing evidence tokens, or headings/tokens placed only inside fenced code.
- Re-run all mandatory gates on the exact updated PR head; previous successful runs do not validate a later commit.
- A regression includes any AutoCAD write/save path, any source hash mutation, or any promotion of unverified snapshot binding to VERIFIED / READY.

## Required fail-closed states

- In-memory AutoCAD Database to on-disk DWG binding remains NEEDS_REVIEW until independently proven.
- INSUNITS is a declaration, not proof of drawing scale; scale remains NEEDS_REVIEW when not independently reconciled.
- Missing host evidence remains UNKNOWN / NOT_RUN.
- AutoCAD 2020 build or NETLOAD failure remains BLOCKED; static contract success cannot be promoted to real runtime PASS.
- No architectural semantics, BIM semantics, regulatory compliance, or edit authorization is inferred from raw CAD extraction.
- Golden DWG fixtures remain immutable; host testing must use a disposable copy.
