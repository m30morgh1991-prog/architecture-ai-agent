# Bug Hunt — PR #132 AutoCAD 2020 host compatibility

## Scope
Add an AutoCAD 2020 build target for the existing Autodesk read-only evidence extractor. Keep the AutoCAD adapter separate from AIE PlanModel, ConstraintMap, architectural rules, and approval logic. No Golden DWG fixture is edited or resaved.

## Findings
- Parent: PR #130, stacked on PR #129.
- Implementation: one shared C# extractor source, compiled separately for AutoCAD 2020 (.NET Framework 4.7) and AutoCAD 2025/2026 (.NET 8 Windows).
- Compatibility correction: use the .NET Framework-provided JavaScriptSerializer for net47 and System.Text.Json for net8. The shared source avoids Convert.ToHexString, which is not an inbox API for .NET Framework 4.7.
- Autodesk managed API references remain host-local and Private=false; the plugin must not ship copies of AcCoreMgd, AcDbMgd, or AcMgd.

## Reproduction / validation
1. Parse the project file and verify both target frameworks are declared.
2. Verify the three Autodesk managed references are non-private.
3. Verify the source uses conditional framework-provided JSON serializers and framework-compatible SHA-256 formatting.
4. Verify the source retains read-only database access, refuses modified/unnamed drawings, keeps snapshot binding NEEDS_REVIEW, and contains no save/write-back call.
5. Run the full Python unit test suite and all mandatory GitHub gates on the exact PR head.
6. Separately, on a Windows host with AutoCAD 2020 and the .NET Framework 4.7 Developer/Targeting Pack, build the net47 target against that installation's managed assemblies and smoke-test only a disposable DWG copy.

## Root cause addressed
The existing Autodesk plugin targeted only net8.0-windows, which excluded the user's preferred AutoCAD 2020 host. Its use of System.Text.Json and Convert.ToHexString also prevented a direct .NET Framework 4.7 build. This PR adds the legacy framework target and replaces those APIs with compatible dependencies/formatting.

## Safety and authority
- Read-only database transactions only.
- Export writes a separate JSON file and never saves the DWG.
- Disk SHA-256 continuity is checked before and after extraction.
- In-memory Database-to-disk byte identity remains unproven; snapshot binding stays NEEDS_REVIEW.
- INSUNITS is a declaration, not proof of scale.
- No architectural semantics, BIM semantics, code compliance, or edit authorization are inferred.
- Golden DWGs remain immutable. Host smoke tests must use a disposable copy.

## CI Verification
- Static compatibility contract tests are added.
- Exact-head PR CI Gate, Runtime Tests, and Mandatory Bug Hunt must complete successfully before merge consideration.
- Python tests and source-level checks do not prove the C# project compiles against AutoCAD 2020.
- AutoCAD 2020 host build and in-host smoke test remain NOT_RUN until performed on a matching Windows/AutoCAD installation.
