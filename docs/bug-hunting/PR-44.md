# Bug Hunt Evidence — PR-44 / H89

## Scope

H89 integrates native DWG detector output into before/after detection snapshots.
The change is limited to runtime snapshot construction and runtime comparison tests.
No edit authority is introduced.

## Bug Hunt

### Reproduction

Exercise runtime snapshot creation with valid native DWG candidates, an approved editable furniture change, a locked fixed-element change, and a missing after-state.

### Root Cause

The primary risk is contract drift between native detector output and the before/after contract: candidate status must be normalized fail-closed, identity/evidence must be preserved, and missing after evidence must not become PASS.

### Findings

- Candidate states outside the allowed set normalize to UNKNOWN.
- Snapshot validation requires source_sha256 and model_id.
- Candidate identity and evidence_ids are retained.
- Missing before/after evidence returns UNKNOWN and never PASS.
- Locked changes remain BLOCKED.
- No edit authority is granted by this adapter.
- UNKNOWN, NEEDS_REVIEW, and BLOCKED states remain fail-closed.

## Regression

Runtime tests cover:
- identity/evidence-aware snapshot construction;
- clean approved editable change;
- locked change blocking;
- missing after-state never passing.

The permanent regression expectation is that detector uncertainty or missing evidence cannot be promoted to PASS.
