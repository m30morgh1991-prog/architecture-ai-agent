## Scope

This change extends the independent, read-only DXF comparator with layer table property comparison and explicit comparator-version provenance. It is scoped to CAD conversion only.

## Changes

- Compare layer table flags, linetype, ACI color, lineweight, plot toggle, and plot-style handle by layer name.
- Include source and candidate layer-property inventories in the comparison report.
- Report a stable comparator version (0.3.0) alongside the existing input SHA-256 values and ezdxf version.
- Add an isolated synthetic regression fixture changing color, lineweight, and plot settings on one layer.
- Preserve read-only behavior and fidelity UNKNOWN / requires_review=true.

## Root Cause / Risk

Previously, the comparator compared layer names but did not compare the layer table's plotting and display properties. Two DXF files could therefore contain identically named layers while differing in color, lineweight, linetype, or plot configuration. The report now makes these differences explicit. This does not establish visual equivalence or conversion fidelity.

## Regression

Run:
python -m unittest tests.test_dxf_comparator -v

The new test isolates layer property changes and verifies both reported property inventories and the structural_differences marker. Existing comparator tests remain required.
