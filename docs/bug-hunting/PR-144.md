## Scope

This change extends the independent, read-only DXF comparator with layer table property comparison and explicit comparator-version provenance. It is scoped to CAD conversion only.

## Bug Hunt

The existing comparator compared layer names but did not compare important layer table properties. This could conceal drawing presentation and plotting differences. The new report records the source and candidate property inventories without modifying either input.

## Findings

- Layer flags, linetype, ACI color, lineweight, plot toggle, and plot-style handle are compared.
- The report records both source and candidate layer property maps.
- Comparator version 0.3.0 is recorded alongside SHA-256 input hashes and ezdxf version.
- Layer property differences are reported as structural_differences.
- This is not a proof of visual equivalence or DWG conversion fidelity.

## Reproduction

Run the comparator regression suite:
python -m unittest tests.test_dxf_comparator -v

The new synthetic test changes color, lineweight, and plot settings on a single layer and checks the report fields and difference marker.

## Root Cause

Layer names alone do not describe layer appearance or plotting behavior. Different lineweights, colors, linetypes, or plot flags can materially alter plotted architectural drawings even when entity geometry is unchanged.

## Regression

The regression fixture writes two independent synthetic DXF files with the same layer name and geometry but different layer table properties. It verifies source and candidate values and confirms that the comparator reports DIFFERENCES_FOUND and layer_properties. Existing geometry, units, dimensions, HATCH, SPLINE, INSERT, Xref, malformed-input, provenance, and read-only tests remain required.

## Required fail-closed states

Unsupported or ambiguous entities remain INCOMPLETE. Parse failures remain COMPARISON_FAILED. Fidelity remains UNKNOWN and review remains NEEDS_REVIEW. No comparison result promotes fidelity to PASS. Missing evidence or unverified execution remains BLOCKED. No false pass is allowed.

## Risk Classification

Low-to-moderate risk. The change reads DXF layer table metadata and serializes primitive values into the report. It does not modify the DXF, alter geometric signatures, or change conversion providers. The main risk is incomplete mapping of layer properties across DXF versions; unsupported or unavailable metadata must not be fabricated.
