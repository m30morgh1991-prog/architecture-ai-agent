# Bug Hunt — P0 canonical HTTP execution authority block

## Scope
Disable the legacy HTTP execution endpoint until it consumes a server-owned, source-hash-bound canonical PlanModel and validated ConstraintMap. Bind the local development server to loopback.

## Bug Hunt
The HTTP adapter previously accepted caller-authored element states and geometry. This allowed request data to act as edit authority without canonical source evidence.

## Findings
The default HTTP path was not connected to a server-side immutable canonical model registry, source-bound ElementEvidenceBundle, validated ConstraintMap, and approval/impact chain. The unauthenticated server entry point also bound to all interfaces.

## Reproduction
Run `python -m unittest tests.test_http_canonical_execution_fail_closed -v`. A forged COLUMN marked EDITABLE is submitted; the endpoint must return HTTP 503 / BLOCKED before reading or trusting the request body.

## Root Cause
The legacy HTTP adapter constructs its PlanModel from client-provided JSON instead of a server-owned canonical snapshot. A client-provided state cannot safely substitute for source-bound evidence.

## Regression
- Execute route rejects before parsing caller-provided elements, geometry, or EDITABLE state.
- Response is CANONICAL_EXECUTION_NOT_CONFIGURED / BLOCKED.
- Default development server binds only to 127.0.0.1.
- No real CAD write is enabled.

## Required fail-closed states
Missing canonical snapshot or source-bound authority remains BLOCKED. Client-supplied EDITABLE, detached ConstraintMap, and approval dictionaries never grant permission. UNKNOWN, SOURCE_REQUIRED, NEEDS_REVIEW, ABSTAIN, and BLOCKED are never promoted to PASS.

## CI Verification
PR CI Gate, Runtime Tests, and Mandatory Bug Hunt must complete successfully on the exact final head. Windows/AutoCAD host execution remains NOT_RUN unless separately exercised.

## Affected Contracts
`runtime/app.py` HTTP boundary and `tests/test_http_canonical_execution_fail_closed.py`. Full canonical integration is not claimed complete.

## Risk Classification
High safety significance, low implementation scope. The endpoint becomes temporarily unavailable rather than allowing untrusted input to authorize edits.

## Negative Tests
- A caller cannot label COLUMN as EDITABLE to obtain execution.
- The route returns BLOCKED before consuming the caller payload.
- The default server bind does not expose the unauthenticated endpoint on all interfaces.

## Unresolved Findings
The server-side canonical snapshot registry and complete source/model identity binding across impact analysis, approval, visual execution, post-edit diff, final validation, and audit remain unimplemented. This PR is interim containment, not completion of issue #160.

## Final Decision
BLOCKED for production execution until canonical integration is implemented. The legacy HTTP endpoint is intentionally fail-closed.
