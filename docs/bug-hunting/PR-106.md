# Bug Hunt — independent runner safety contract (PR #106)

## Scope
Add a deterministic policy contract and tests for the future unattended AI runner. This PR does not implement provider calls or autonomous code execution.

## Bug Hunt
Checked positive, negative, fail-closed, duplicate-PR, provider-configuration, and invalid-state paths. No secrets or live repository write permissions are used by this module.

## Findings
- The policy contract is deterministic and side-effect-free.
- Only explicit success for all required gates permits isolated task work.
- The contract never authorizes merge or H-stage advancement.
- Missing provider configuration blocks AI execution.

## Reproduction
Run python -m unittest tests/test_independent_runner_policy.py -v and python -m unittest discover -s tests -p 'test_*.py' -v on the exact PR head.

## Root Cause
An unattended runner needs a machine-checkable boundary so missing, stale, or incomplete state cannot be mistaken for permission to implement or advance the project.

## Regression
Regression tests assert pending, missing, failed, cancelled, skipped, unknown, and absent gate values are blocked. Tests also assert that merge and stage advancement are never authorized.

## Required fail-closed states
UNKNOWN, NEEDS_REVIEW, and BLOCKED must never be promoted to PASS. Missing provider configuration, invalid SHA, invalid stage, incomplete gates, or an unresolved agent PR blocks task execution. A false pass is prohibited.

## CI Verification
Exact-head PR CI, Runtime Tests, Mandatory Bug Hunt, and the independent runner policy tests must complete successfully before merge. At evidence creation time, final PR head and its checks are not yet verified; pending/unobserved is not PASS.

## Affected Contracts
runtime/independent_runner_policy.py; tests/test_independent_runner_policy.py; docs/automation/INDEPENDENT_RUNNER_DESIGN.md; .github/workflows/pr-ci-gate.yml; .github/workflows/test.yml; .github/workflows/bug-hunt-gate.yml.

## Risk Classification
Medium: this is a new governance authorization contract. It is currently not wired to execute external commands, call a model, change repository files, merge PRs, or unlock stages.

## Negative Tests
Negative tests cover invalid SHA, invalid stage, absent gate snapshot, pending gate, missing gate, absent provider configuration, unknown PR state, and an existing agent PR. They assert can_merge=false and can_advance_stage=false.

## Unresolved Findings
- No AI execution provider or credential is configured/verified; autonomous code generation is not yet operational.
- The new policy module is a deterministic contract only; wiring it into a least-privilege runner is future work.
- Repository ruleset Min currently requires zero approving reviews; human review enforcement remains a separate governance improvement.
- H100 remains active and H101 remains locked.

## Final Decision
BLOCKED until exact-head PR CI, Runtime Tests, Mandatory Bug Hunt, and the new policy tests are completed/success. PASS is not claimed before those results are observed.
