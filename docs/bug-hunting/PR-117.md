# Bug Hunt — PR #117 AgentShield pilot

## Scope
Adds one advisory GitHub Actions workflow for security scanning of coding-agent configuration surfaces. No runtime application code, architecture understanding logic, PlanModel, ConstraintMap, provider credentials, application dependencies, or Golden DWG assets are changed.

## Bug Hunt
The first PR-specific evidence report failed the mandatory schema check because required headings/tokens were missing. After correcting that report, the next real run passed the Bug Hunt gate. Reviewing the same run exposed a separate defect: the scanner step used an unpublished npm version and an unsupported output-format value. Because the step is advisory and uses continue-on-error, the workflow job showed success even though the scanner itself failed. This is a real integration defect, not a security pass.

## Root Cause
Two independent issues were identified:
1. The original Bug Hunt report did not conform to the existing evidence schema, so the gate correctly blocked it.
2. The workflow pinned ecc-agentshield@1.2.0, which the npm registry rejected with ETARGET, and used --format text although the documented format is terminal. The advisory wrapper preserved a green job status despite scanner failure. The workflow is corrected to use the published ecc-agentshield@1.6.0 and --format terminal, and its summary explicitly warns that a successful job is not equivalent to a successful scan.
