# Bug Hunt — PR 49 / H90

## Scope
Verify PostEditDiff derives only from before/after detection and preserves Source-of-Truth identity and fail-closed behavior.

## Bug Hunt
Reproduction covered clean approved edits, locked changes, unauthorized changes, missing before/after evidence, source identity mismatch, and added/removed elements.
Root cause: H90 called a validation method that existed on DetectionSnapshot but was missing on BeforeAfterDetection. The runtime missing-evidence path also discarded source/model identity, causing the PostEditDiff identity gate to reject the intended UNKNOWN result.
Contract drift was isolated between BeforeAfterDetection, runtime_before_after, and post_edit_diff_validation.

## Findings
The failure was a real integration/contract bug, not a flaky CI issue. UNKNOWN, NEEDS_REVIEW, and BLOCKED states remain fail-closed. No edit authority is introduced. Identity mismatch, added, removed, locked, and unauthorized deltas remain blocking.

## Regression
Permanent H90 tests cover clean approved change, locked change, unauthorized change, missing before/after, identity mismatch, and added/removed elements. The missing-evidence runtime path now preserves source/model identity and returns UNKNOWN rather than producing an invalid partial object. Any future regression must be added before merge.
