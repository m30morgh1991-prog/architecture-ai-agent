# Bug Hunt — Educational Architectural Drawing References (Clean Integration)

## Bug Hunt

## Scope
Documentation-only integration of the user-provided architectural drawing-reading reference and catalog-verified candidate references. No runtime behavior is changed.

## Findings
The principal risks are source conflation, treating catalog listings as studied content, and promoting educational examples into current regulatory authority. The documents distinguish studied material from catalog-verified/not-yet-studied candidates and preserve provenance boundaries.

## Reproduction
Inspect the PR diff and the three reference files under docs/knowledge/. Run the repository CI, Runtime Tests, and this mandatory Bug Hunt gate on the exact final PR head.

## Root Cause
The project had educational source material and research leads that needed a traceable repository record, but the previous integration branch was divergent from current main. The content has been ported to a fresh branch from current main to avoid stale-base merge risk.

## Regression
No runtime, PlanModel, ConstraintMap, ApprovedChangePlan, or Golden DWG files are changed. The change adds educational documentation and a pointer in Architecture Understanding Core only.

## Required fail-closed states
UNKNOWN, SOURCE_REQUIRED, NEEDS_REVIEW, ABSTAIN, and BLOCKED remain unresolved states and must never be promoted to PASS from educational prose alone. Catalog-verified sources remain NOT YET STUDIED until the actual edition is obtained and reviewed.
