# PR-73 Bug Hunt — H100 Golden DWG SHA-256 evidence

## Scope
Validate that the H100 Golden Understanding source-hash test computes SHA-256 from the actual checked-out Golden DWG bytes.

## Bug Hunt
- Verify both preserved Golden DWG paths exist.
- Compute SHA-256 from file bytes.
- Reject missing files, malformed digests, or placeholder hashes.
- Do not confuse Git object/blob SHA with file SHA-256.
- Do not promote source-hash evidence to Golden Understanding PASS.
- Treat any failed governance/runtime gate as a merge blocker.

## Findings
The first PR-73 Bug Hunt run was blocked by missing PR-specific evidence. The second run then exposed two evidence-contract omissions: the reproduction token and an explicit unresolved state. No functional regression was indicated by Runtime Tests or PR CI.

## Root Cause
The PR evidence was written as a narrative summary but did not satisfy the repository's machine-checkable Bug Hunt contract for reproduction and unresolved state.

## Reproduction
Run:
`python -m unittest tests/test_bug_hunting_gate.py -v`
Then:
`python runtime/bug_hunting_gate.py --pr-number 73`
For the source-hash regression:
`python -m unittest tests/test_golden_source_hashes.py -v`

## Regression
The Runtime test remains responsible for machine-checking both Golden DWG files and printing:

The test is evidence collection only; Golden Understanding remains fail-closed until the full H100 evidence and UG gates are satisfied.
