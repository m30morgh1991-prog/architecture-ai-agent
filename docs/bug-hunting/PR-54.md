# H94 Visual DWG Evidence Hardening — Bug Hunt

## Scope
Harden the real visual DWG adapter so optional header metadata does not make a valid DWG unreadable.

## Bug Hunt
Reproduction: provide a valid DWG through an ezdwg-compatible document whose header_variables API is unavailable or raises.
Root cause: DWG ingestion treated optional extents metadata as mandatory parsing evidence.
Finding: a parser/API difference could incorrectly produce DWG_PARSE_FAILED before native entity evidence was available.
Fix: header metadata is now optional; entity ingestion remains the source of native evidence and missing extents remain unknown.

## Findings
UNKNOWN header extents remain UNKNOWN.
Missing header evidence never becomes PASS.
Native entity evidence is still processed.
No compliance or edit authority is granted by successful parsing.

## Regression
Added a permanent regression using a fake DWG document without header_variables.
Existing native candidate tests remain in place.

## CI Verification
Required before merge: exact-head Bug Hunt, Runtime Tests, and PR CI. Mainline verification remains separate after merge.

## Final Decision
Merge only if the regression passes and exact-head CI is successful.

### Governance-state verification
The evidence explicitly records that UNKNOWN and unresolved states remain fail-closed; no UNKNOWN, NEEDS_REVIEW, or BLOCKED state is promoted to PASS.
