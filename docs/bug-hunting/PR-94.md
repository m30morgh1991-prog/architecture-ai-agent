# Bug Hunt — H100 Scale/Unit Fail-Closed Contract

## Bug Hunt

## Scope
Harden the existing deterministic scale/unit evidence contract so it cannot return PASS when the resolved unit is UNKNOWN or invalid.

## Findings
The previous evaluator could count two truthy evidence flags as sufficient even when the selected unit resolved to UNKNOWN. The dataclass validation checked confidence and scale_known but did not require a known unit for PASS.

## Reproduction
Run \`python -m pytest tests/test_scale_unit_evidence.py -q\`.

## Root Cause
Signal presence and unit-value resolution were conflated. Boolean evidence flags could be selected as if they were unit values, and PASS validation did not enforce a resolved unit.

## Regression
Unit values are normalized separately from evidence-presence flags. Unsupported unit labels remain NEEDS_REVIEW; conflicting explicit/header units become BLOCKED. Two signals with no resolvable unit become NEEDS_REVIEW, and direct construction of PASS with unit UNKNOWN is rejected.

## Required fail-closed states
PASS requires a known unit, scale_known=true, confidence >= 0.95, source identity, and evidence IDs. Missing or unresolvable units remain UNKNOWN/NEEDS_REVIEW; explicit conflicts are BLOCKED.

## CI Verification
Do not merge until PR CI Gate, Runtime Tests, and Bug Hunt Gate are completed/success on the exact final head.

## Affected Contracts
\`runtime/scale_unit_evidence.py\` and \`tests/test_scale_unit_evidence.py\`. No geometry, PlanModel, ConstraintMap, or drawing source is changed.

## Risk Classification
Medium. Unit errors can change dimensions and scale interpretation, so an unsupported PASS can propagate into geometry decisions.

## Negative Tests
- Multiple signals with unit UNKNOWN do not PASS.
- Unit strings equal to UNKNOWN do not count as verified unit evidence.
- Unsupported unit labels such as MILLIMETERS remain NEEDS_REVIEW and cannot be masked by other truthy flags.
- Conflicting units become BLOCKED.
- PASS with unit UNKNOWN is rejected.
- Valid unit strings normalize consistently.

## Unresolved Findings
Connecting extracted drawing metadata into this contract, verifying actual dimension-to-geometry associations, scale ratio evidence, cross-view consistency, and real-world Golden adversarial cases remain pending.

## Final Decision
BLOCKED until exact-head PR CI, Runtime Tests, and Bug Hunt Gate are all green.

PASS is allowed only when the resolved unit is known and evidence is sufficient.
false pass prevention: unknown units never become PASS.
exact-head verification is mandatory.
