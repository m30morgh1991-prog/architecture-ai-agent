## Scope

This increment extends read-only DXF comparison for nested block definitions and INSERT orientation. It changes only CAD conversion code and tests.

## Bug Hunt

The prior INSERT signature captured insertion point, scale, rotation, array parameters, and attached attributes, but omitted the OCS extrusion vector. Two block references with different orientations could therefore receive the same supported signature. The comparator version is advanced to 0.4.0.

## Findings

- INSERT extrusion is now included in the semantic signature using the configured numeric tolerance.
- Synthetic tests cover INSERT extrusion changes, nested block-definition geometry changes, and nested INSERT transform changes.
- No DXF input is modified.
- The comparator does not establish DWG-to-DXF fidelity or visual equivalence.

## Reproduction

Run `python -m unittest tests.test_dxf_comparator -v`. The regression tests create independent temporary DXF files and isolate the changed INSERT or nested-block property.

## Root Cause

INSERT placement is defined in an object coordinate system. The extrusion vector determines the orientation of that coordinate system. Omitting it allowed an orientation change to escape the INSERT fingerprint.

## Regression

The new tests assert DIFFERENCES_FOUND for distinct extrusion vectors, nested block geometry, and nested INSERT rotation. They also assert fidelity UNKNOWN and requires_review. Existing tests for geometry, layer properties, units, dimensions, HATCH, SPLINE, attributes, Xrefs, malformed files, provenance, and read-only inputs remain required.

## Required fail-closed states

Fidelity remains UNKNOWN and review remains NEEDS_REVIEW. Unsupported or ambiguous content remains INCOMPLETE or BLOCKED as appropriate. No uncertain comparison is promoted to PASS. No false pass is permitted.

Pending, missing, failed, or stale-SHA checks remain BLOCKED. Local or synthetic regression evidence is not a substitute for exact-head CI PASS.

## Affected Contracts

Only the CAD DXF comparator and its tests are affected. PlanModel, ConstraintMap, ApprovedChangePlan, BIM understanding, and architectural semantic contracts are unchanged. The comparator remains read-only.

## Risk Classification

Low-to-moderate risk. The change adds one geometric orientation vector to an existing INSERT signature. The principal risk is unsupported or malformed OCS metadata; the implementation must remain conservative and never fabricate values beyond the DXF default extrusion.

## Negative Tests

- A different INSERT extrusion must be detected.
- A nested block geometry change must be detected.
- A nested INSERT transform change must be detected.
- Identical supported content must retain fidelity UNKNOWN and NEEDS_REVIEW.
- Malformed input must remain COMPARISON_FAILED.
