## Scope

PR #138 adds a standalone GeometryReference contract and focused tests. No parser, geometry mutation, unit normalization, PlanModel integration, or Windows/AutoCAD host behavior is changed.

## Bug Hunt

Review focused on false unit conversion, paper/model scale confusion, unsupported evidence promotion, malformed transforms, and source provenance. The principal false pass risk is treating a unit label, paper scale, or transform matrix as proof without source evidence.

## Findings

- Geometry units and paper scale must remain separate.
- A paper scale such as 1:100 must not be applied to model-space coordinates.
- A declared unit without SUPPORTED status and evidence must not enable square-metre conversion.
- Raster calibration must reject singular and non-finite transforms.
- OCS/WCS and nested INSERT transforms remain unresolved and outside this PR.

## Reproduction

The negative tests construct unsupported units, unsupported coordinate frames, missing paper-scale ratios, singular raster transforms, non-finite transform values, duplicate evidence IDs, and invalid source hashes. These are deterministic contract-level reproductions; no native DWG parsing is claimed.

## Root Cause

The current understanding contracts do not have a single explicit geometry-reference object that separates linear unit, coordinate frame, sheet scale, raster calibration, and dimension reconciliation. This gap makes accidental conflation possible at future integration points.

## Regression

The new tests verify that UNKNOWN unit status cannot authorize metric area, that paper scale does not establish model units, and that malformed or unsupported calibration evidence is rejected. The implementation is additive and leaves existing geometry paths unchanged.

## Required fail-closed states

UNKNOWN, NEEDS_REVIEW, and BLOCKED remain valid outcomes. Unsupported or contradictory evidence must never be promoted to SUPPORTED or PASS. No compliance or editing permission follows from this contract.

## Risk Classification

Medium integration risk, low immediate runtime risk. The contract is not yet wired into PlanModel/SpaceModel. False pass risk is specifically metric conversion without supported unit evidence or paper-scale leakage into model coordinates.

## Negative Tests

- Missing evidence for a SUPPORTED unit is rejected.
- Missing evidence for a SUPPORTED coordinate frame is rejected.
- Paper scale without a ratio is rejected.
- Raster calibration without an affine transform is rejected.
- Singular, non-finite, and boolean transform values are rejected.
- Duplicate evidence IDs and invalid source hashes are rejected.

## Unresolved Findings

DWG header-to-geometry unit reconciliation, OCS/WCS resolution, nested INSERT transforms, PDF page calibration, raster pixel-to-world calibration, and dimension-to-geometry reconciliation remain unresolved findings. These require separate source adapters and golden regression evidence.
