## Scope

- `runtime/plan_revision_diff.py`
Update README install/test/governance guidance. No existing runtime module, workflow, PlanModel/ConstraintMap/ApprovedChangePlan contract, BIM contract, or Golden DWG fixture is modified. This PR does not wire the new helpers into the runtime pipeline.

## Bug Hunt
The change addresses missing reusable contracts for evidence-backed findings, pre-understanding drawing-input completeness checks, and comparing two PlanModel revisions. Fail-closed behavior is required: no unsupported inference, no false pass, and no implicit approval path.

## Findings
- A finding without evidence is rejected; an empty report resolves to UNKNOWN rather than PASS.
- A human disposition never changes a finding's status. BLOCKED/BLOCKING findings cannot be overridden, and human_review_complete does not authorize editing.
- Missing input metadata produces SOURCE_REQUIRED; explicit contradictory flags produce BLOCKED; raster geometry and inch-unit plotting uncertainty produce NEEDS_REVIEW. Placeholder scale/unit strings (UNKNOWN, ?, TBD, N/A, etc.) are not accepted as supplied evidence; malformed or zero-valued scale ratios and unrecognized/unitless unit tokens remain NEEDS_REVIEW.
- Revision diff now requires traceable CoordinateSystemEvidence: matching frame IDs, recognized canonical units on both models, and non-empty evidence IDs. Different units (e.g. mm vs inches) or unknown/unitless units block the comparison even when numeric coordinates are identical. Coordinate evidence IDs are propagated into the resulting revision findings for audit traceability. Any removal or modification of a LOCKED/protected base element is BLOCKED; renumbered elements are not guessed to be the same element.
- The code is additive and is not yet integrated into runtime execution. That limitation remains explicit and is not counted as runtime integration evidence.

## Root Cause
The repository had individual validation contracts but no single normalized findings/report contract, no explicit gate for source metadata completeness before understanding, and no dedicated comparison of two PlanModel revisions. These additions close those contract gaps without changing the Source of Truth or edit authorization flow.
