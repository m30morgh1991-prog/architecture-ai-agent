# Bug Hunt — PR #184 (AI-01 confidence validation)

## Scope
Reject non-finite and invalid external-detector confidence values in the adapter. Boolean values are rejected as numeric confidence. Invalid values normalize to confidence 0.0 and state UNKNOWN. Valid finite numeric values retain the existing clamping behavior.

## Reproduction
Focused tests cover NaN, positive and negative infinity, string representations of NaN/Infinity, None, non-numeric strings, and booleans. The pre-fix local snapshot reproduced NaN/Infinity normalization to 1.0 and True normalization to 1.0.

## Security invariant
Invalid confidence must not be interpreted as strong evidence or permit promotion to LOCKED/EDITABLE. Invalid confidence fails closed to UNKNOWN.

## Validation
The focused adapter tests passed locally after the fix (4 test methods, including multiple subcases). CI is required for exact-head validation; full project tests were not run locally.

## Risk / boundaries
This change is confined to external detector confidence normalization and tests. It does not change PlanModel/ConstraintMap authority, protected element classification, BIM, Golden DWG inputs, workflows, or execution. No merge or approval is performed here.
