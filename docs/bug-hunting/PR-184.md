## Scope

AI-01 confidence validation in the external detector adapter. Invalid confidence values are rejected as evidence, confidence is set to 0.0, and state remains UNKNOWN.

## Bug Hunt

Source inspection identified unsafe handling of non-finite confidence: float NaN could survive min/max clamping and be interpreted as a strong score in downstream comparisons. The patch rejects non-finite values and boolean confidence.

## Findings

AI-01: NaN and Infinity were not explicitly rejected before clamping. Invalid numeric values could produce unsafe confidence semantics. This finding is fixed in this PR, subject to exact-head CI and review.

## Reproduction

Regression tests exercise NaN, positive/negative Infinity, string forms, None, nonnumeric strings, and boolean values. Invalid values assert confidence 0.0 and state UNKNOWN. Focused tests passed locally (4 test methods with subcases). This is a targeted reproduction, not an exhaustive security audit.

## Root Cause

The adapter relied on float conversion and max/min clamping without a finite-number check. Non-finite values have special comparison behavior, so clamping is insufficient. A finite-number check is now required before clamping.

## Regression
