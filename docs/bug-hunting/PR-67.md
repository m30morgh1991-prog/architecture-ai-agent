# Bug Hunt Evidence — PR 68

## Scope
H100 semantic and drawing evidence foundation: symbols, linework, text/OCR provenance,
dimensions, levels, section/elevation markers, reconciliation, and binding into PlanModel.

## Reproduction
Before this change, drawing-language observations had no single source-bound contract
for provenance, contradiction, or missing-evidence decisions. Reproduction is the
absence of a canonical contract connecting those observations to PlanModel.

## Root cause
The existing H98/H99 chain had element evidence and architectural relations, but
drawing-language evidence was fragmented across metadata/native helpers and was not
bound to PlanModel as one validated evidence set.

## Bug Hunt
- No second PlanModel or semantic graph is introduced.
- UNKNOWN/CONTRADICTED evidence cannot be promoted by confidence alone.
- Section PASS requires direction and cut-plane semantics.
- Dimensions require measured and extension geometry references.
- Levels require explicit elevation evidence.
- Contradictory facts become CONTRADICTED; missing requirements become NEEDS_REVIEW.

## Findings
1. Drawing evidence is source-SHA bound and requires source provenance.
2. PlanModel can carry DrawingEvidenceSet without making it authoritative when unresolved.
3. PlanUnderstandingCore propagates unresolved drawing evidence to UNKNOWN.
4. Existing scale, native drawing, topology, relation and BIM modules remain the canonical
   owners for their existing responsibilities.
