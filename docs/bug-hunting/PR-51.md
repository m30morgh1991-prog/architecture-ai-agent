# H91 Final Validation Contract — Bug Hunt

## Scope
Audit and harden final validation so PASS requires source/model identity, approved scope, validated before/after evidence, validated post-edit evidence, and complete audit evidence.

## Bug Hunt
Reproduction: a shallow final gate could return PASS from a small set of booleans while missing before/after uncertainty, identity, scope, or audit evidence.
Root cause: final validation was not represented as a fail-closed contract with explicit evidence states.
Categories: Logic Bug, Contract Bug, Validation Bug, Fail-Closed Bug.

## Findings
- UNKNOWN must never become PASS.
- NEEDS_REVIEW must never become PASS.
- BLOCKED must never become PASS.
- Missing/invalid source identity blocks.
- Missing audit evidence blocks.
- Changed IDs outside approved scope block.
- No edit authority is granted by this validation contract; it only validates evidence after an approved operation.

## Regression
Tests cover clean PASS, missing audit, UNKNOWN, NEEDS_REVIEW, BLOCKED, invalid identity, and unauthorized scope.
Each discovered defect is intended to remain a permanent regression case.

## CI Verification
This branch must pass Bug Hunt Gate, Runtime Tests, and PR CI on the exact head SHA before merge. Local green is not sufficient.

## Final Decision
PASS means the required evidence is complete and consistent; otherwise the result is UNKNOWN, NEEDS_REVIEW, or BLOCKED. Merge only after exact-head CI verification.
