# H91 Final Validation Contract — Bug Hunt

## Scope
Harden final validation with explicit source/model identity, approved scope, before/after evidence, post-edit evidence, and audit completeness.

## Bug Hunt
Reproduction: final validation could rely on shallow booleans and miss required evidence.
Root Cause: the final gate lacked a dedicated fail-closed contract.
Findings: identity, evidence state, scope, and audit completeness must be explicit.

## Findings
UNKNOWN, NEEDS_REVIEW, and BLOCKED are never PASS.
Any unresolved evidence state is never PASS.
Invalid source identity blocks.
Incomplete audit blocks.
Unauthorized changed IDs block.
The contract validates evidence and does not grant edit authority.

## Regression
Regression tests cover PASS, missing audit, UNKNOWN, NEEDS_REVIEW, BLOCKED, invalid identity, unauthorized scope, and unresolved evidence.

## CI Verification
Exact-head Bug Hunt, Runtime Tests, and PR CI are required before merge. Local green is not sufficient.

## Final Decision
PASS only when required evidence is complete and consistent. Otherwise BLOCKED or NEEDS_REVIEW. Merge only after exact-head CI verification.
