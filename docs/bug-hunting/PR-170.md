# Bug Hunt — P0 canonical HTTP execution authority block

## Scope
Disable the legacy HTTP execution endpoint until it consumes a server-owned, source-hash-bound canonical PlanModel and validated ConstraintMap. Bind the local development server to loopback.

## Findings
The previous route parsed client-supplied elements, geometry, and LOCKED/EDITABLE state into the legacy runtime PlanModel. This allowed request data to act as edit authority without canonical source evidence. The route also started on 0.0.0.0 in the default entry point.

## Reproduction
Run `python -m unittest tests.test_http_canonical_execution_fail_closed -v`. The regression sends a forged COLUMN with state EDITABLE and verifies the route returns HTTP 503 / BLOCKED before reading or trusting the request body. The second regression verifies loopback binding.

## Root Cause
The HTTP adapter is not integrated with a server-side immutable canonical model registry, source-bound ElementEvidenceBundle, validated ConstraintMap, and approval/impact chain. A client-provided PlanModel cannot safely substitute for those records.

## Regression
- The execute route rejects before parsing client-provided elements or state.
- The rejection is explicit: CANONICAL_EXECUTION_NOT_CONFIGURED / BLOCKED.
- The unauthenticated development server binds only to 127.0.0.1.
- The legacy in-process simulator remains available for isolated tests; this change does not enable real CAD writes.
- No PlanModel, ConstraintMap, BIM, Golden DWG, or architectural detection semantics are promoted or modified.

## Required fail-closed states
Missing canonical snapshot or source-bound authority remains BLOCKED. Client-supplied EDITABLE, approval dictionaries, and detached ConstraintMap data never grant permission. UNKNOWN, SOURCE_REQUIRED, NEEDS_REVIEW, ABSTAIN, and BLOCKED are never promoted to PASS.

## CI Verification
PR CI Gate, Runtime Tests, and Mandatory Bug Hunt must complete successfully on the exact final head. Windows/AutoCAD and Golden DWG host execution remain NOT_RUN unless separately exercised in the user's Windows environment.

## Affected Contracts
`runtime/app.py` HTTP boundary and `tests/test_http_canonical_execution_fail_closed.py`. Canonical integration is intentionally not claimed complete.

## Risk Classification
High safety significance, low implementation scope. The endpoint becomes temporarily unavailable rather than allowing untrusted input to authorize edits.

## Negative Tests
- A caller cannot label COLUMN as EDITABLE to obtain execution.
- The route returns BLOCKED before consuming the caller payload.
- The default server bind does not expose the unauthenticated endpoint on all interfaces.

## Unresolved Findings
The canonical server-side snapshot registry and complete source/model identity binding across impact analysis, approval, visual execution, post-edit diff, final validation, and audit remain to be implemented. This PR is an interim containment fix, not completion of issue #160.

## Final Decision
BLOCKED for production execution until canonical integration is implemented. The legacy HTTP endpoint is intentionally fail-closed.
