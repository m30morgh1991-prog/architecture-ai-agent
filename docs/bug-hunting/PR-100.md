# Bug Hunt — Pre-phase H100 coherence and governance audit (PR #100)

## Bug Hunt

## Scope
Reconcile stale project-state documents, remove the PR target-branch filter that prevented CI from running on stacked/dependency PRs, and record the verified branch-ruleset blocker without claiming administrative changes that this integration cannot perform.

## Findings
- `PROJECT_STATE.md`, `MASTER_HANDOFF.md`, and `docs/PROJECT_PROGRESS_CHECKLIST.md` were stale relative to live GitHub state: they described PR #75 as the current point and PR #93 as in progress even though PR #93 was merged into main.
- PR CI Gate and Runtime Tests only triggered for pull requests targeting `main`, unlike Bug Hunt Gate. This forced dependency PRs to be temporarily retargeted just to obtain validation.
- Repository ruleset `Min` (ID `24680937`) is disabled, has no target refs, and has no required status checks; branch governance is not enforced by that ruleset.
- Technical COMMENT reviews are now recorded on PRs #96–#100; these are not independent approvals. Green checks and COMMENT reviews do not equal independent approval.

## Reproduction
1. Read the current main commit and PR #93 metadata: main is `2842cf2523fb9140b72f03a2311addf06c468af2`; PR #93 is merged.
2. Fetch `PROJECT_STATE.md`, `MASTER_HANDOFF.md`, and `docs/PROJECT_PROGRESS_CHECKLIST.md`; compare their latest-state statements.
3. Read `/.github/workflows/pr-ci-gate.yml` and `/.github/workflows/test.yml`; both previously limited pull_request events to base branch `main`.
4. Read `/repos/m30morgh1991-prog/architecture-ai-agent/rulesets/24680937`; enforcement is disabled, include/exclude refs are empty, and required_status_checks is empty.
5. Read review collections for PR #96, #97, #98, and #99; all returned empty arrays.

## Root Cause
Project state had not been reconciled after PR #93 merged. Two workflow files retained a main-only pull_request base-branch filter while Bug Hunt Gate already accepted all PR bases. The configured ruleset had been created but not activated or targeted at the main branch.

## Required fail-closed states
- Do not claim post-merge mainline Green without actual evidence for the merge commit.
- Do not treat completed PR-head checks as review approval or active branch protection.
- Do not merge PR #99 before prerequisite PR #98; after #98 merges, rebase/retarget #99 and rerun gates on the final exact head.
- H100 remains active; H101 remains locked.
- Golden DWG assets remain immutable and uncertain semantic domains remain UNKNOWN/NEEDS_REVIEW/BLOCKED as appropriate.

## Regression
- PR CI Gate now listens to `pull_request` events without a base-branch filter.
- Runtime Tests now listens to `pull_request` events without a base-branch filter.
- Main-only push triggers are retained.
- Bug Hunt Gate already listens to all pull_request events.
- Project-state documents now record the live PR/gate status and unresolved ruleset activation.
- No Golden DWG assets or runtime semantic authority contracts were changed.
