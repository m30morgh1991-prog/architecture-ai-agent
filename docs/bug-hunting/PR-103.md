# Bug Hunt — H100 Golden Scale/Unit Bridge (PR #103)

## Bug Hunt

## Scope
Expose source-bound native DWG unit metadata in the Golden Understanding report without treating a unit declaration as verified drawing scale.

## Findings
The scale/unit contract is now present on current main after PR #102, but Golden Understanding did not expose the detector's DWG unit metadata as a report domain. The bridge must preserve the newer evaluator and must not copy stale versions of the evaluator, tests, or project-state files.

## Reproduction
Run `python -m unittest discover -s tests -p "test_dwg_scale_unit_bridge.py" -v`, `python -m unittest discover -s tests -p "test_golden_understanding_runner.py" -v`, and `python -m unittest discover -s tests -p "test_golden_source_hashes.py" -v`. Run the full PR CI, Runtime Tests, Mandatory Bug Hunt, and Golden Understanding regression on the exact final head.

## Root Cause
The Golden Understanding report emitted dimensions as UNKNOWN but did not expose a scale/unit observation from the native DWG detector's `dwg_units` metadata. The previous PR branch also overlapped with the refreshed fail-closed scale/unit evaluator, so this integration was rebuilt directly on current main and intentionally preserves the merged evaluator and shared state.

## Required fail-closed states
- Recognized unit metadata alone is NEEDS_REVIEW, never PASS.
- Missing, unitless, malformed, unsupported, string-typed, or boolean metadata remains UNKNOWN.
- Dimensions remain UNKNOWN until dimension-to-geometry evidence is independently verified.

## Regression
The bridge maps only recognized DXF `$INSUNITS` values: 1=inches, 2=feet, 4=millimetres, 5=centimetres, 6=metres. Unsupported and unitless codes remain unknown. The Golden manifest allows only UNKNOWN or NEEDS_REVIEW for scale_unit, while other unresolved semantic domains remain UNKNOWN.

The merged `runtime/scale_unit_evidence.py` contract and its tests are retained unchanged.

## Risk Classification
Medium. Misreading unit metadata as verified scale can corrupt dimensional interpretation. The bridge deliberately does not promote dimensions or scale to PASS.

## Negative Tests
- Recognized unit metadata remains NEEDS_REVIEW without independent scale/dimension evidence.
- Unitless, unsupported, missing, string-typed, and boolean metadata remain UNKNOWN.
- Blocked reports retain UNKNOWN scale/unit evidence.
- Golden manifest disallows PASS for scale_unit and keeps other unresolved domains UNKNOWN.
- Golden source SHA-256 evidence remains unchanged; no Golden DWG asset is modified.

## Unresolved Findings
Explicit scale-ratio extraction, dimension-to-geometry association, reconciliation of unit labels in text/title blocks, and cross-view scale consistency remain unresolved and require separate source-bound evidence and Golden regression.

## Final Decision
BLOCKED until exact-head PR CI, Runtime Tests, Mandatory Bug Hunt, and applicable Golden regression are all green.
