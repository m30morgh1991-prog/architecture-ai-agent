# Bug Hunt — H100 DWG Negative Evidence Hardening

## Bug Hunt

## Scope
Harden the DWG CandidateFact reconciliation boundary so contradiction and required-evidence references are source-bound to the same DrawingEvidenceSet.

## Findings
The pre-existing bridge preserved contradiction IDs but trusted caller-provided references. A missing or foreign reference could influence reconciliation without first proving provenance continuity.

## Reproduction
Run `python -m unittest tests/test_dwg_evidence_reconciliation.py -v`.

## Root Cause
Contradiction and required-evidence reference collections were passed directly to `reconcile_fact` without membership/source validation against the current DrawingEvidenceSet.

## Regression
The fix validates every contradiction and required-evidence reference, rejects missing references, rejects cross-source references, and rejects overlap where the supporting evidence is also declared as contradictory.

## Required fail-closed states
UNKNOWN, NEEDS_REVIEW, BLOCKED, and CONTRADICTED must never be promoted to PASS. Invalid provenance references must raise a blocking validation error.

## CI Verification
Exact-head PR CI, Runtime Tests, and Bug Hunt must complete successfully before merge. A pending or unobserved workflow is not Green.

## Affected Contracts
`runtime/dwg_evidence_reconciliation.py`, `runtime/evidence_reconciliation.py`, `runtime/drawing_semantic_evidence.py`.

## Risk Classification
High: contradiction/negative-evidence is a semantic promotion boundary; accepting unbound evidence could create a false PASS.

## Negative Tests
Missing contradiction reference, missing required-evidence reference, support/contradiction overlap, UNKNOWN evidence, UNCERTAIN evidence, and missing CandidateFact evidence reference are covered.

## Unresolved Findings
This PR does not claim full architectural semantic understanding. Level/section/scale semantics, real-world adversarial Golden fixtures, and H100 semantic PASS remain pending.

## Final Decision
BLOCKED until exact-head REAL CI and Bug Hunt gates are green.

false pass prevention: unbound or unresolved negative evidence cannot become authoritative PASS.
exact-head verification is mandatory.
